## Funcionalidad

- Administración reservada a usuarios activos con rol Administrador.
- Creación en un área activa, con nombre de 3–100 caracteres tras trim y
  descripción opcional de hasta 255. IDs enteros positivos y `activa` booleana.
- Edición parcial de nombre/descripción/estado; conserva campos omitidos y área.
- Nombre único por área sin distinguir mayúsculas ni tildes, incluidas las
  categorías inactivas. El índice MySQL protege también carreras concurrentes;
  su error se traduce a 409.
- Desactivación sin borrar categorías ni modificar casos existentes; reactivación.
- Catálogo agrupado por área con activas, inactivas y cantidad de casos.
- `/categorias.html`: formulario de creación/edición/cancelación y botones
  Activar/Desactivar, doble envío bloqueado, textos conservados ante errores y
  presentación de nombres/descripciones como texto.
- `/api/categorias/areas`: áreas activas, incluso sin categorías, para crear
  la primera categoría de un área vacía. Las áreas no se gestionan.

CP-38 crea un caso de Impresora en la base temporal, desactiva su categoría
desde la página, verifica que desaparece del formulario de registro y sigue
visible en Mis casos. Compara las filas del caso antes/después y reactiva la
categoría. Las pruebas no borran ni actualizan esos casos.

Los intentos concurrentes de crear la misma categoría devuelven un 201 y un
409; al renombrar dos categorías al mismo nombre, un 200 y un 409. Nunca quedan
duplicados. La prueba de navegador provoca un 500 mediante un trigger temporal
para comprobar que conserva el formulario y permite reintentar.

Se crean y eliminan bases `campushelp_hu11_test_*` y
`campushelp_hu11_browser_test_*` y perfiles temporales de Chrome.
No se ejecuta `db:init` ni se modifica la base `campushelp`.

## Repetir las pruebas

Requiere las credenciales MySQL de `.env`, permisos para crear bases y triggers
temporales, y Chrome/Edge. El navegador requiere Node.js 22+.

```powershell
$env:CAMPUSHELP_TEST_MYSQL = '1'
$env:CAMPUSHELP_TEST_BROWSER = '1'
try { npm.cmd test } finally {
  Remove-Item Env:CAMPUSHELP_TEST_MYSQL
  Remove-Item Env:CAMPUSHELP_TEST_BROWSER
}
```

Para ejecutar solo esta historia, con las mismas variables:

```powershell
node --test tests/services/gestionarCategorias.test.js tests/api/categorias.test.js tests/categorias.mysql.test.js tests/browser/categorias.mysql.test.js
```

Para revisar la interfaz: iniciar la aplicación, abrir `/categorias.html` y
seleccionar a Fabio Administrador. Crear una categoría, editarla, desactivarla
y reactivarla; comprobar los cambios en el catálogo de registro y la cantidad
de casos. El esquema existente ya soporta esta historia; no necesita migración.
